# Tunify: A Copyright-Free Music Website

Tunify is a simple and user-friendly music website that allows users to listen to a wide variety of music tracks. Built using HTML, CSS, and JavaScript, it provides a seamless browsing experience with a clean and responsive design.

## Features

- **Browse and Play Music**: Users can listen to music from a variety of tracks available on the platform.
- **Responsive Design**: The website is fully responsive, providing a smooth experience across different devices and screen sizes.
- **Simple and Clean Interface**: The layout is minimalistic and easy to navigate.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP (optional for future features like user data, etc.)
- **Hosting**: XAMPP (Local Server)
